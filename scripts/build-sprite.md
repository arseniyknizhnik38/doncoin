# Как собран спрайт персонажа

`client/public/don-outsider.webp` — лента из 8 кадров, вырезанная из
исходного видео. Видео в проект не кладём: 3,9 МБ грузились бы каждую сессию,
а спрайт весит 142 КБ.

Чтобы пересобрать (нужен ffmpeg, например `npx ffmpeg-static`):

```bash
ffmpeg -y -i ИСХОДНОЕ_ВИДЕО.mp4 \
  -vf "trim=0:1,setpts=PTS-STARTPTS,fps=8,format=rgba,colorkey=0xEDE3E1:0.14:0.06,scale=192:192:flags=neighbor,tile=8x1" \
  -frames:v 1 -c:v libwebp -lossless 1 client/public/don-outsider.webp
```

Что делает каждый кусок:

- `trim=0:1` — берём первую секунду; дальше движение повторяется;
- `fps=8` — 8 кадров, этого хватает для заметной анимации при малом весе;
- `colorkey=0xEDE3E1` — убираем светлый фон исходника, иначе на тёмной теме
  вокруг персонажа был бы квадрат. Цвет взят пипеткой из угла кадра;
- `scale=...:flags=neighbor` — масштабирование без сглаживания, иначе
  пиксель-арт замылится;
- `tile=8x1` — склейка кадров в одну ленту;
- `-lossless 1` — для пиксель-арта сжатие с потерями даёт грязь на границах.

Если поменяется число кадров, поправьте `background-size` и `steps()`
в `.don-sprite` (client/src/index.css) — там зашито 8.
