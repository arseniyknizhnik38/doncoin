# Как собран спрайт персонажа

`client/public/don-outsider.webp` — лента из 8 кадров, вырезанная из
исходного видео. Видео в проект не кладём: 3,9 МБ грузились бы каждую
сессию, а спрайт весит 138 КБ.

Инструменты нужны только для пересборки, в зависимостях проекта их нет:

```bash
npm i -D ffmpeg-static pngjs
```

## 1. Кадры

```bash
npx ffmpeg -y -i ИСХОДНОЕ_ВИДЕО.mp4 \
  -vf "trim=0:1,setpts=PTS-STARTPTS,fps=8,scale=192:192:flags=neighbor" \
  -frames:v 8 frames/f%02d.png
```

`flags=neighbor` — масштабирование без сглаживания, иначе пиксель-арт
замыливается.

## 2. Вырезание фона

```bash
node scripts/cut-sprite-background.mjs frames strip.png
```

Скрипт заливает прозрачностью **только связную область от краёв кадра** и
останавливается на тёмном контуре персонажа.

Так сделано не случайно: первая версия убирала все пиксели, похожие на цвет
фона, и вместе с фоном исчезли белки глаз и белая майка — они оказались
достаточно близки к нему по цвету.

## 3. Сборка в WebP

```bash
npx ffmpeg -y -i strip.png -c:v libwebp -lossless 1 client/public/don-outsider.webp
```

Сжатие без потерь: у пиксель-арта на границах иначе появляется грязь.
## Если меняется число кадров

Поправьте в двух местах:

- `client/src/index.css` — ширину `.don-strip` (`800%` = 8 кадров);
- `client/src/game/TapCoin.tsx` — константу `SPRITE_FRAMES`.

## Почему смена кадров сделана в коде, а не в CSS

Два подхода уже сломались, и оба одинаково — персонаж пропадал при тапе.

**`background-position` в процентах.** Там процент считается от разницы
размеров картинки и элемента, а не от ширины кадра. При ленте из восьми
кадров «шаг на 100%» уводил её сразу за границы.

**CSS-анимация со `steps()` по `transform`.** На десктопе работала верно, а на
мобильных движках последний шаг иногда отрисовывается конечным значением
ключевого кадра (`-100%`), и лента снова уезжает целиком из окна.

Сейчас номер кадра лежит в состоянии компонента, сдвиг считается явно
(`кадр × 12.5%` от ширины ленты), а таймер крутится только пока идут тапы.
Это ведёт себя одинаково во всех движках.
